# End-to-end Recommender System for Steam Games

This projects features a full end-to-end AWS based Recommender System, integrating AI coding subagents for each
component, described below:

| COMPONENT NAME | DIRECTORY       | DESCRIPTION                                                                                                                                                                                                                                                                                                                                                                                                             |
|----------------|-----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Data Ingestion | @data_ingestion | Consists on a containerized job (via AWS Fargate) to scrape the Steam API for game reviews given the game id, a lambda function in @data_ingestion/reviews_partitioner_lambda in order to submit the scraping jobs on multiple workers partitioned by game ids, and a lambda function on @data_ingestion/new_items_lambda that takes all the new game ids and uploads the necessary features to the feature store / ANN |
| ETL            | @etl            | dbt based transformations with AWS Athena backend, to perform feature engineering on the raw parquet scraped data, resulting in an Iceberg dataset for offline training and evaluation of retrieval and ranking models.                                                                                                                                                                                                 |
| Training       | @training       | Responsible of taking the processed Iceberg tables from the ETL in order to train retrieval and ranking models, while also including writing to the ANN and versioning new models as part of the pipeline                                                                                                                                                                                                               |
| Serving        | @serving        | Lightweight FastAPI app to serve the final recommender system. Fetched the user id -> user features from online feature store -> ANN candidate retrieval -> item features -> business rules filtering -> ranking model -> LLM reranking                                                                                                                                                                                 |
| Infrastructure | @infrastructure | Necessary AWS infrastructure (terraform), including ECS Fargate + ALB for serving, EventBridge + ECS RunTask for dbt on Athena, EventBridge + Lambda + AWS Fargate for scraping, MemoryDB for ANN and Online feature store                                                                                                                                                                                              |
